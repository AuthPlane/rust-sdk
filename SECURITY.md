# Security Policy

If you believe you have found a security issue in the Authplane Rust SDK, please do not open a public issue.

Instead, report it privately to the Authplane maintainers through the security contact or private disclosure channel used for the Authplane SDK family.

When reporting, include:

- affected crate(s) and version(s)
- a concise description of the issue
- reproduction steps or a proof of concept
- impact and any suggested mitigations, if known

We will acknowledge reports, investigate them, and coordinate disclosure and fixes with affected repositories when needed.
