# Authplane Rust SDK — Complete LLM Reference

> Cargo workspace for protecting MCP servers and OAuth 2.1 resource servers
> with tokens issued by an Authplane authorization server. Contains the
> framework-agnostic SDK (`core/`) and an MCP adapter (`mcp/`) as
> independently publishable crates.

## When To Use This Repository

Use this repo when you need to:
- modify typed OAuth / Authplane error models or their mapping from OAuth
  token endpoint payloads
- evolve circuit-policy decisions for OAuth errors
- wire the typed errors into the [rmcp](https://crates.io/crates/rmcp) Rust
  MCP framework (`mcp/`) or [fastmcp-rust](https://crates.io/crates/fastmcp-rust) (`fastmcp/`)
- tune URL-elicitation (`-32042`) behavior in the adapter

## Layering Rules (Important)

1. Typed errors, OAuth mapping, and circuit policy live only in `core/`.
2. The adapters (`mcp/`, `fastmcp/`) must stay thin: detect consent /
   interaction-required SDK errors and raise framework-specific errors.
3. Do not duplicate error types or OAuth mapping in the adapter.
4. Preserve typed metadata for consent flows (`service_id`, `cause_detail`,
   `consent_url`).
5. Adapter wrappers stay minimal and stateless.
6. Each crate is published independently on crates.io; the adapter depends
   on `authplane-sdk` through the workspace's `path = "../core"` dep.

## Error Model (`core/`)

- `AuthError` — generic OAuth / API failure shape.
- `ConsentRequiredError` — typed variant for `consent_required` and
  `interaction_required`.
- `AuthplaneError` — SDK-level error enum exposing both.

### OAuth Mapping Behavior

`map_oauth_error(status_code, payload)` maps:

- `consent_required` and `interaction_required` → `ConsentRequiredError`
- any other OAuth error → `AuthError`

When building a `ConsentRequiredError`:

- `service_id` is derived from `service_id`, then `service`, then
  `resource`, with fallback `unknown_service`.
- `cause_detail` comes from `cause` if present, else `error_description`.
- `consent_url` is read from `consent_url` when available.

### Circuit Policy

`should_open_circuit_for_oauth_error(code)` must *not* open the circuit for
expected client-class OAuth failures, including:

- `invalid_grant`, `invalid_client`, `unauthorized_client`
- `invalid_scope`, `invalid_target`
- `consent_required`, `interaction_required`

## URL Elicitation Mapping (adapter)

The adapter raises URL-elicitation errors when all of the following are true:

1. SDK error is `AuthplaneError::ConsentRequired(_)`.
2. OAuth code is `consent_required` or `interaction_required`.
3. `consent_url` is present on the `ConsentRequiredError`.

The elicitation payload includes `mode: "url"`, the `url`, an
`elicitationId`, and a contextual message derived from the service and cause
details.

### `mcp/` — `authplane-mcp`

- Targets `rmcp`.
- Emits `rmcp::model::ErrorData` with
  `ErrorCode::URL_ELICITATION_REQUIRED` (`-32042`).

The adapter exposes a small, stateless API:

- `to_url_elicitation_required_error(error)`
- `wrap_tool_with_url_elicitation(handler)`

### `fastmcp/` — `authplane-fastmcp`

- Targets `fastmcp-rust` (0.3+, which supports both stdio and HTTP).
- Emits `fastmcp_rust::McpError` with `McpErrorCode::Custom(-32042)`.

Same stateless API shape:

- `to_url_elicitation_required_error(error)`
- `wrap_tool_with_url_elicitation(handler)`

## Examples

### 1) Parse a token-exchange error (`core`)

```rust
use authplane_sdk::{AuthplaneError, parse_token_exchange_error};

let body = r#"{
  "error":"consent_required",
  "error_description":"Consent needed",
  "service_id":"drive",
  "consent_url":"https://example.com/consent"
}"#;

match parse_token_exchange_error(Some(400), body) {
    AuthplaneError::ConsentRequired(consent) => {
        assert_eq!(consent.service_id, "drive");
    }
    AuthplaneError::Auth(_) => unreachable!("expected consent-required mapping"),
}
```

### 2) Circuit policy (`core`)

```rust
use authplane_sdk::should_open_circuit_for_oauth_error;

assert!(!should_open_circuit_for_oauth_error("consent_required"));
assert!(should_open_circuit_for_oauth_error("server_error"));
```

### 3) rmcp mapping (`mcp/`)

```rust
use authplane_sdk::AuthplaneError;
use authplane_mcp::to_url_elicitation_required_error;

fn map(error: AuthplaneError) {
    if let Err(mcp_error) = to_url_elicitation_required_error(error) {
        eprintln!("mapped MCP error code: {}", mcp_error.code.0);
    }
}
```
